# CRISP-DM (Cross Industry Standard Process for Data Mining)

## 1. Business Understanding
Tahap memahami tujuan bisnis dan menerjemahkannya ke dalam tujuan data mining.

### Tujuan:
- Menentukan tujuan bisnis
- Menyusun rencana proyek
- Mengidentifikasi sumber daya, kendala, asumsi, dan risiko

### Output:
- Inventaris sumber daya (SDM, data, hardware, software)
- Daftar persyaratan & kendala
- Identifikasi risiko proyek

---

## 2. Data Understanding
Tahap memahami karakteristik dan kualitas data.

### Proses:
- Mengumpulkan data awal
- Mendeskripsikan data (jumlah record, atribut, format)
- Eksplorasi data (statistik, visualisasi, hubungan antar variabel)
- Verifikasi kualitas data (missing value, error, inkonsistensi)

### Output:
- Laporan deskripsi data
- Laporan eksplorasi data
- Laporan kualitas data

---

## 3. Data Preparation
Tahap menyiapkan dataset final untuk pemodelan.

### Proses:
- Seleksi data (memilih atribut & record relevan)
- Cleaning data (menangani missing value & error)
- Integrasi data (menggabungkan beberapa tabel)
- Transformasi data jika diperlukan

### Output:
- Dataset siap modeling
- Dokumentasi proses persiapan data

---

## 4. Modeling
Tahap membangun model untuk menjawab kebutuhan bisnis.

### Proses:
- Memilih metode (Statistik, Machine Learning, AI)
- Menentukan variabel model
- Melatih dan menguji model
- Evaluasi performa model

---

## Pengertian Data Mining
Data Mining adalah proses mengekstraksi pengetahuan atau pola yang berguna dari database besar menggunakan teknik statistik, matematika, dan machine learning.

### Istilah lain:
- Knowledge Discovery in Database (KDD)
- Knowledge Extraction
- Business Intelligence
- Data Analysis
