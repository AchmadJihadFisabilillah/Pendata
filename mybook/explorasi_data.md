# Eksplorasi Data Dataset Iris

Eksplorasi data (Exploratory Data Analysis / EDA) merupakan tahap awal dalam proses data mining yang bertujuan untuk memahami karakteristik dataset sebelum dilakukan analisis lanjutan atau pembangunan model.

Pada proyek ini dilakukan eksplorasi terhadap **Dataset Iris**, salah satu dataset klasik dalam bidang machine learning yang sering digunakan untuk pembelajaran klasifikasi dan analisis statistik.

Tujuan eksplorasi ini adalah:
- Memahami struktur dataset
- Menghitung statistik deskriptif
- Menganalisis distribusi fitur
- Mengidentifikasi hubungan antar variabel
- Menentukan fitur yang paling membedakan antar kelas

# Business Understanding

## Latar Belakang

Dataset Iris digunakan untuk menganalisis perbedaan karakteristik tiga jenis bunga iris berdasarkan ukuran kelopak (sepal) dan mahkota (petal).

Analisis ini dapat digunakan sebagai dasar dalam:
- Klasifikasi jenis bunga
- Pengenalan pola
- Implementasi algoritma machine learning

## Tujuan Analisis

1. Mengidentifikasi karakteristik masing-masing species
2. Menentukan fitur yang paling berpengaruh
3. Menyediakan dasar untuk tahap data mining selanjutnya
